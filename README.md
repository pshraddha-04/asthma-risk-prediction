## Overview

The dataset is imbalanced, so three balancing techniques are compared (SMOTE, ROSE, Hybrid). Feature importance is assessed using three methods (LASSO, RFE, Boruta). Four ML models are trained and evaluated across three train/test split ratios and four feature subsets — resulting in **27 experiment configurations** in total.

The best-performing Neural Network model is saved and deployed via a Shiny web application.

---

## Dataset

- **File:** `Asthma_Disease_Dataset.csv` — place manually in the `data/` folder before running any scripts.
- **Target variable:** `Diagnosis` (0 = Non-Asthmatic, 1 = Asthmatic)
- **Dropped columns:** `PatientID`, `DoctorInCharge` (non-informative identifiers)

> The raw dataset is not included in this repository. You can obtain it from [Kaggle](https://www.kaggle.com/) or your own source.

## Workflow

> ⚠️ All scripts must be run from the **project root** (`DS_CP/`) so that relative paths resolve correctly.

```r
setwd("path/to/DS_CP")
```

| Step | Script | Description |
|------|--------|-------------|
| 1 | `scripts/01_data_balancing.R` | Balances the dataset using SMOTE, ROSE, and Hybrid sampling. Saves 3 CSVs to `data/`. |
| 2 | `scripts/02_feature_selection.R` | Runs LASSO, RFE, and Boruta on SMOTE-balanced data. Prints ranked feature importance. |
| 3 | `scripts/modeling/<method>/<technique>/<split>.R` | Trains and evaluates all 4 models on 4 feature sets. Prints a results table. |
| 4 | *(manual)* | Save the best Neural Network model to `models/neural_network_top9.rda`. |
| 5 | `shiny::runApp("shiny_app")` | Launches the prediction web app. |

## Data Balancing

The original dataset is class-imbalanced. Three techniques are applied and compared:

| Method | Description |
|--------|-------------|
| **SMOTE** | Synthetic Minority Over-sampling Technique — generates synthetic samples for the minority class |
| **ROSE** | Random Over-Sampling Examples — creates a balanced sample using smoothed bootstrapping |
| **Hybrid** | Combination of over-sampling (minority) and under-sampling (majority) via `ovun.sample` |

---

## Feature Selection

Feature importance is evaluated using three independent methods on the SMOTE-balanced dataset:

| Method | Description |
|--------|-------------|
| **LASSO** | L1-regularized logistic regression — shrinks unimportant feature coefficients to zero |
| **RFE** | Recursive Feature Elimination — iteratively removes least important features using Random Forest |
| **Boruta** | Wrapper around Random Forest — confirms features as important, unimportant, or tentative |

## Models & Configurations

Four classifiers are trained per configuration:

| Model | Package |
|-------|---------|
| Random Forest | `randomForest` |
| SVM (radial kernel) | `e1071` |
| XGBoost | `xgboost` |
| Neural Network | `nnet` |

Each model is evaluated across:
- **3 balancing methods** × **3 feature selection techniques** × **3 train/test splits** = **27 scripts**
- Each script tests **4 feature sets** × **4 models** = **16 results per script**

### Train/Test Splits

| Script | Train | Test |
|--------|-------|------|
| `70_30.R` | 70% | 30% |
| `75_25.R` | 75% | 25% |
| `80_20.R` | 80% | 20% |

### Evaluation Metrics

- Accuracy
- Sensitivity (Recall)
- Specificity
- Precision
- F1 Score

## Shiny App

The Shiny app loads the saved Neural Network model (`models/neural_network_top9.rda`) and predicts asthma diagnosis from user-entered patient details.

### Input Features

| Feature | Type |
|---------|------|
| Nighttime Symptoms | Binary (Yes/No) |
| Chest Tightness | Binary (Yes/No) |
| Wheezing | Binary (Yes/No) |
| History of Allergies | Binary (Yes/No) |
| Exercise-Induced Symptoms | Binary (Yes/No) |
| Age | Numeric (5–79) |
| Gender | Binary (Male/Female) |
| Shortness of Breath | Binary (Yes/No) |
| Family History of Asthma | Binary (Yes/No) |

### Output

- **Asthmatic** — displayed with a red alert
- **Non-Asthmatic** — displayed with a green alert

### Launch

```r
setwd("path/to/DS_CP")
shiny::runApp("shiny_app")
```
